# 3AX-UI: установка одной командой

Неинтерактивный установщик [3AX-UI](https://github.com/coinman-dev/3ax-ui) с поддержкой AmneziaWG и импорта конфигураций в AmneziaVPN.

## Установка

Подключитесь к новому VPS по SSH под `root` и выполните:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/yavasilek/3ax-ui-installer/main/install.sh)
```

В конце команда выведет:

```text
URL: https://IP-АДРЕС.sslip.io:ПОРТ/СЕКРЕТНЫЙ-ПУТЬ/
Username: admin_...
Password: ...
```

Реквизиты также сохраняются в `/root/3ax-ui-credentials.txt` с правами `600`. Файл создаётся сразу после применения логина и пароля к панели, до финальных HTTPS/AWG-проверок. Если одна из них завершится ошибкой, реквизиты всё равно будут показаны вместе с ошибкой, а повторный запуск продолжит установку.

## Что делает скрипт

- ставит последнюю стабильную версию официального 3AX-UI;
- устанавливает утилиты и DKMS-модуль AmneziaWG, затем создаёт тестовый интерфейс;
- создаёт случайные логин, пароль, порт и секретный URL-путь;
- формирует домен вида `185-105-226-75.sslip.io` без ручной настройки DNS;
- получает доверенный сертификат Let's Encrypt и включает его автопродление;
- открывает нужные TCP-порты в активном UFW или firewalld;
- устанавливает Fail2Ban и защищает фактический SSH-порт через nftables;
- задаёт для AWG проверенный на мобильной сети UDP-порт `30526` (или свободный порт `20000–39999`, если он занят);
- не добавляет маршрут `::/0` клиентам, которым сервер не выдал IPv6-адрес;
- проверяет службу и HTTPS перед показом реквизитов.

Если выпуск сертификата сорвётся, панель останется доступна только локально. После устранения причины достаточно повторить ту же команду — установка продолжится.

## Требования

- чистый VPS с Debian 11+ или Ubuntu 22.04+;
- `root`, systemd, архитектура amd64 или arm64;
- ядро Linux 5.6+ и желательно не менее 1 ГБ RAM;
- свободный и доступный из интернета TCP-порт `80` для Let's Encrypt;
- во внешнем файрволе хостинга должен быть разрешён выбранный TCP-порт панели.

Скрипт намеренно не перезаписывает чужую установку `x-ui`/`3AX-UI` и останавливается, если порт 80 уже занят.

Перед установкой также проверяется состояние `dpkg`/APT. Если единственная проблема — устаревшая привязка `grub-pc`, скрипт автоматически определяет целый загрузочный диск, проверяет его несколькими способами, сохраняет прежнее состояние debconf и завершает настройку пакета. При неоднозначной дисковой схеме установка останавливается без записи загрузчика.

Для AmneziaWG установщик выбирает совместимую ветку официального PPA: Focal для Debian 11, Jammy для Debian 12/Ubuntu 22.04 и Noble для Debian 13/Ubuntu 24.04+. Ключ репозитория скачивается отдельно и принимается только при совпадении полного fingerprint; устаревшие записи PPA, оставленные предыдущим установщиком, заменяются с резервной копией. Устанавливаются системные зависимости полного серверного запуска (`iptables`, `nftables`, `ndppd`, `sqlite3`). Проверка теперь поднимает и удаляет временный AWG 2.0-сервер через `awg-quick` с диапазонами H1-H4, I1, адресом, MTU, NAT и forwarding-правилами — пустой интерфейс больше не считается достаточным тестом.

При повторном запуске установщик читает только состояние AWG-сервера из базы 3AX-UI. Если сервер включён, но интерфейс не поднят, панель перезапускается и сохранённый конфиг запускается повторно. Клиенты, ключи и настройки не пересоздаются; после успешного запуска проверяются имя интерфейса, UDP-порт и правило активного firewall.

На новом сервере AWG получает UDP-порт `30526`: этот порт проверен на том же мобильном клиенте AmneziaWG, тогда как случайные порты из верхнего эфемерного диапазона могут молча фильтроваться оператором. Если у VPS уже есть служба на этом UDP-порту, установщик автоматически выбирает свободный порт в диапазоне `20000–39999`. Для IPv4-only VPS создаётся совместимое правило базы: новые клиентские конфиги получают `AllowedIPs = 0.0.0.0/0`, без неработающего `::/0`. Нативный IPv6 при его наличии не меняется.

Если предыдущий запуск уже поставил панель, но оборвался на сообщении `The awg utility is missing`, просто повторите обновлённую однострочную команду. Сохранённое состояние будет использовано для продолжения, повторная установка панели не требуется.

## Защита SSH

Установщик сам определяет SSH-порт из текущего подключения, конфигурации OpenSSH и активного сокета. Затем он создаёт jail `sshd`: 5 неудачных попыток за 10 минут блокируют адрес на 1 час, а повторные блокировки постепенно увеличиваются до 1 суток. Используется журнал systemd и nftables; текущий IP администратора не добавляется в вечный белый список.

Проверить защиту после установки:

```bash
fail2ban-client status sshd
```

Конфигурация сначала проверяется командой `fail2ban-client -t`. Если она не проходит проверку или jail не запускается, установщик возвращает прежний файл Fail2Ban и останавливается. Служба SSH при этом не перезапускается.

## Необязательные параметры

Задать порт панели заранее:

```bash
PANEL_PORT=50409 bash <(curl -fsSL https://raw.githubusercontent.com/yavasilek/3ax-ui-installer/main/install.sh)
```

Задать UDP-порт AmneziaWG заранее:

```bash
AWG_PORT=30526 bash <(curl -fsSL https://raw.githubusercontent.com/yavasilek/3ax-ui-installer/main/install.sh)
```

На уже настроенном сервере смена AWG-порта требует явного подтверждения, потому что после неё клиентские конфиги нужно экспортировать и импортировать заново:

```bash
AWG_PORT=30526 AWG_RECONFIGURE_EXISTING=1 bash <(curl -fsSL https://raw.githubusercontent.com/yavasilek/3ax-ui-installer/main/install.sh)
```

Использовать свой домен, который уже указывает на VPS:

```bash
PANEL_DOMAIN=vpn.example.com bash <(curl -fsSL https://raw.githubusercontent.com/yavasilek/3ax-ui-installer/main/install.sh)
```

Зафиксировать конкретную версию 3AX-UI:

```bash
THREE_AX_VERSION=v2.3.5 bash <(curl -fsSL https://raw.githubusercontent.com/yavasilek/3ax-ui-installer/main/install.sh)
```

## AmneziaVPN

После входа откройте **AWG Settings**, включите сервер, проверьте параметры AmneziaWG 2.0 и нажмите **Сохранить настройки**, затем добавьте клиентов. Клиентский QR-код или `.conf` можно импортировать как в отдельный клиент AmneziaWG, так и в приложение AmneziaVPN.

## Ошибка `grub-pc ... does not exist`

Она означает, что Debian запомнил старый идентификатор загрузочного диска и оставил пакет `grub-pc` недонастроенным. Установщик исправляет этот случай автоматически, только когда `/boot` однозначно сопоставлен с обычным целым диском и проверки GRUB/sysfs совпадают. Для LVM/RAID на `/boot`, нескольких неоднозначных дисков, read-only или съёмных устройств автоматическая запись запрещена — скрипт остановится с диагностикой.

> Выполнение удалённого скрипта от `root` всегда требует доверия к репозиторию. Для предварительной проверки скачайте `install.sh`, прочитайте его и только затем запустите `bash install.sh`.
